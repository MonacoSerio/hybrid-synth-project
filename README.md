# Hybrid Synth Project

Educational synthesizer project developed during my Electronic Engineering studies.

The goal is to progressively design and understand the fundamental building blocks of electronic sound synthesis, combining analog and digital techniques.

## Current Status

Phase 1 completed:
- NE555 astable oscillator
- Passive buzzer output
- Frequency control through potentiometer

## Project Goals

- Understand oscillator design
- Learn analog signal generation
- Explore sound synthesis fundamentals
- Document the engineering process
- Build a complete educational synthesizer

## Technologies

- NE555
- Breadboard prototyping
- Arduino
- Passive buzzer
- Analog electronics
